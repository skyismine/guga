# 第一轮:核心Bug修复 — 修改说明

> 原则:纯增量修改、不改 LightGBM 预测 / VectorBT 特征核心、复用现有数据接口、输出中性合规。
> 提交范围:`app/decision/engine.py`、`app/support/settings.py`、`app/web/server.py`。

## 修复项1:板块-标的信号矛盾

**问题**:板块标注「核心主攻」,但个股建议为「卖出」,层级冲突。

**改动**(`engine.py`):

1. 统一 5 档操作信号口径(全系统统一命名):
   `关注低吸 / 突破跟进 / 持有观察 / 减仓兑现 / 观望`(按强度降序),
   由 advisor 原始动作映射:`buy→关注低吸, add→突破跟进, hold→持有观察, reduce→减仓兑现, sell/wait→观望`。
2. 新增「板块等级修正系数」:`_adjust_signal()` 对标的信号叠加板块溢价:
   - 核心主攻:整体上修 1 档(不再出现卖出/观望);
   - 防御备选 / 观察池:板块不修正(位置修正仍生效)。
3. 新增「位置修正因子」:
   - 低位启动(近3日涨幅 <5% 且 >0):信号上修 1 档;
   - 短期高位(近3日涨幅 ≥15%):信号下修 1 档。
4. 每只标的输出 `adj_notes` 信号修正说明(如:「核心主线溢价上修 1 档」「短期高位(近3日 +15.3%),信号下修防回落」)。
5. `match_level_targets(sector_name, sector_level)` 新增 sector_level 参数,decision_brief 按板块等级传入。

**配置**(`settings.py` → `decision.signal`):

```
enabled       总开关(默认开)
levels        5 档信号名称
sector_boost  板块修正档位: core=1, defensive=0, watch=0
low_pos_ret3d   低位阈值(0.05)
high_pos_ret3d  高位阈值(0.15)
note          输出修正说明(默认开)
```

## 修复项2:执行参数数值全链路自洽

**问题**:目标价=现价、分批反向、回踩区间跨度过大、风险金额与股数不匹配。

**改动**(`engine.py` → `execution_plan`):

1. 第一目标价 = 现价 × (1 + 0.5×ATR/现价),且强制 ≥ 现价×1.03,禁止等于/低于现价;
2. 第二目标价 = 近 20 日平台压力位(VectorBT `levels.resistance`);若低于第一目标强制递增到第一目标;
3. 分批与触发强绑定,两种模式二选一(配置 `plan.mode`: auto|pullback|breakout):
   - **回踩低吸**:首批 60% = 支撑上沿(5日线),二批 40% = 支撑下沿(10日线),触发「回踩支撑区间 X~Y 缩量企稳」;
   - **突破跟进**:首批 60% = 压力位突破价,二批 40% = 突破后回踩确认价,触发「放量突破压力位 X 确认,回踩 Y 不破再关注」;
4. 回踩区间限定 5日线~10日线,跨度上限 8%(超限压缩);中期强支撑(`levels.support`)单独列为「极端加仓位 deep_support」,不混入短线区间;
5. 止损 = min(原止损, 二批价×0.97),强制低于加权买入成本(0.6×一批+0.4×二批),否则取加权成本×0.98;
6. 股数公式:以**加权买入成本**为基准 —— 建议股数 = (总资金 × 单笔风险比例) ÷ (加权成本 - 止损),
   再受单票上限截断(市值×单票比例);输出股数/仓位金额/预计最大亏损金额/占总资金比例;
   自洽校验:实际仓位 vs 风险公式推算仓位偏差 ≤5%(受单票上限截断时以截断后为准);
7. 执行参数输出新增 `mode` / `mode_note`,Web 页面标注分批模式。

**配置**(`settings.py` → `decision.plan`):

```python
mode              分批模式: auto|pullback(回踩低吸)|breakout(突破跟进)
pullback          第一/二批挂单线: ma5 / ma10(支撑上沿/下沿)
breakout          第一/二批挂单线: resistance / confirm(压力位/回踩确认)
target1_atr_mult  目标价 ATR 倍数(0.5)
target1_min_gain  目标价最低涨幅(3%)
pullback_span_max 回踩跨度上限(8%)
position_check_tol 仓位自洽校验容差(5%)
```

## 修复项3:主线分级与评分倒挂

**问题**:黄金评分高于重组蛋白却分级更低;成长赛道被标防御。

**改动**(`engine.py`):

1. 新增属性池划分 `_sector_pool(name)`:
   - 进攻池关键词:CRO/创新药/半导体/AI/算力/机器人/新能源/军工等(可配置);
   - 防御池关键词:黄金/消费/煤炭/电力/公用事业/银行等(可配置);
   - 未命中默认归进攻池(`pool.default`)。
2. 分级重构:先分池再池内排名,禁止跨池对比:
   - 核心主攻 = 进攻池综合得分第 1 名(满足准入);
   - 防御备选 = 防御池综合得分第 1 名(满足准入);
   - 观察池 = 其余得分 ≥ 准入线,降序;
3. 强制校验(`mainline_check.enforce`):观察池任一板块得分不得高于防御备选,倒挂则调整标签并标注「属性不匹配,原评分高于防御备选,归入防御备选」。

**配置**(`settings.py` → `decision.pool` / `mainline_check`):

```python
pool.aggressive_kw / defensive_kw / default
mainline_check.enforce / fallback
```
